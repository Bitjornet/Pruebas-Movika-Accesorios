# Pruebas-Movika-Accesorios

Página web para digitalizar las ventas de un negocio de joyería de plata que hoy atiende sus pedidos por WhatsApp. Proyecto académico de Informática III (UNAM FES Cuautitlán), desarrollado por el Equipo 2 con el modelo en cascada.

## Descripción

El sistema permite llevar el control de ventas con:

- Catálogo de productos
- Registro de clientes
- Pedidos con fecha de compromiso obligatoria
- Cancelación de pedidos con motivo
- Prioridad para los pedidos atrasados

## Tecnologías

- HTML, CSS y JavaScript
- GitHub para el control de versiones
- Vercel para el despliegue
